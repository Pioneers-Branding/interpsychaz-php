==================================================
HOW TO RUN & VIEW THE WEBSITE
==================================================

Option 1 — PHP Local Development Server (Recommended):
  1. Open a terminal in this project folder.
  2. Run:
       npm run dev
     or:
       php -S localhost:8000 router.php
  3. Open http://localhost:8000 in your browser.
  All clean URLs, dropdowns, blog posts, and forms will work seamlessly.

Option 2 — Static HTML Build:
  1. Run:
       npm run build
     or:
       node build.js
  2. Output will be generated into the `public/` directory with 120+ pages.
  3. Serve the static site:
       npx serve public
     or open `public/index.html`.

Option 3 — Apache / XAMPP / WAMP:
  1. Place the project folder into your htdocs / web root.
  2. Ensure mod_rewrite is enabled (the included .htaccess handles routing).
  3. Access via http://localhost/<project-folder-name>/
